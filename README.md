# AI-kunskap

Enkla förklaringar av begrepp inom AI, med bilder och vardagliga liknelser. Sidorna är skrivna på svenska för den som inte är tekniker.

## Sidor

| Sida | Innehåll |
|---|---|
| [Vad är MCP?](vad-ar-mcp.html) | Model Context Protocol: hur AI-assistenter kopplas till andra system, de tre delarna värd, klient och server, ett exempel steg för steg, säkerhet och skillnaden mellan API och MCP. |
| [Vad är MoE?](vad-ar-moe.html) | Mixture of Experts: hur en router väljer några få experter per ord, riktiga siffror från Mixtral och DeepSeek-V3 samt för- och nackdelar. |
| [AI om 1, 3 och 5 år](ai-om-1-3-5-ar.html) | Framtidsspaning från oktober 2026: kontrollerade fakta om läget, en tidslinje till 2031, bedömningar för 1, 3 och 5 år, tre scenarier och råd för en kommun. |

`index.html` är en startsida som länkar till alla sidor.

## Så visar du sidorna

- **På datorn:** ladda ner repot och öppna `index.html` i en webbläsare.
- **På webben:** slå på GitHub Pages för repot (Settings → Pages, välj grenen och mappen `/`). Då får sidorna en egen adress.

Varje sida är en fristående HTML-fil utan byggsteg. Typsnitten hämtas från Google Fonts; utan nätverk används systemets typsnitt i stället. Sidorna följer datorns ljusa eller mörka läge och fungerar på mobil.
