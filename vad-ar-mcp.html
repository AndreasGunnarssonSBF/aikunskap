AI-kunskap · Grunder

Vad är MCP?

MCP står för Model Context Protocol. Det är ett gemensamt sätt för AI-assistenter att koppla upp sig mot andra program, till exempel din kalender, dina filer eller en databas.

Kort sagt: MCP är som en USB-C-kontakt, fast för AI.

Problemet

En AI är smart, men sitter instängd

En AI-assistent vet bara två saker: det den lärde sig när den tränades, och det du skriver till den. Den kan inte själv titta i din kalender, öppna ett dokument på jobbet eller söka i ett register.

För att AI:n ska kunna hjälpa till på riktigt behöver den alltså en koppling till de här systemen. Det är det MCP ger.

Varför behövs det?

Före och efter MCP

Förr behövde varje AI-app en egen, specialbyggd koppling till varje system. Tre appar och fyra system blev tolv olika kopplingar att bygga och underhålla.

Med MCP pratar alla samma språk. Varje app och varje system ansluts en gång till standarden, och sedan fungerar allt ihop.

Hur det är uppbyggt

Tre delar som samarbetar

MCP har tre roller. Tänk på det som en restaurang: du pratar med servitören, servitören går till köket, och köket hämtar från skafferiet.

Host · värd

AI-appen

Programmet du använder, till exempel Claude. Här finns AI-modellen. Som servitören som tar emot din beställning.

Client · klient

Kopplingen i appen

En liten del inne i appen som håller kontakten med en server. En klient per server.

Server · server

Översättaren

Ett litet program som vet hur ett visst system fungerar, till exempel kalendern. Som köket som vet var allt finns.

Vad kopplingen ger

Vad kan en MCP-server erbjuda?

En server berättar för AI:n vad den kan hjälpa till med. Det finns tre sorter.

Verktyg

Låter AI:n göra något.

Boka ett möte, skicka ett mejl, skapa ett ärende.

Resurser

Låter AI:n läsa något.

Ett dokument, en tabell, en lista med kontakter.

Promptar

Färdiga mallar för vanliga uppgifter.

”Sammanfatta det här ärendet” eller ”Skriv ett svar till medborgaren”.

Ett exempel

Steg för steg: ”Vilka möten har jag i morgon?”

Så här går det till när du ställer en fråga som AI:n inte kan svara på själv.

  1. Du frågar AI-appen: ”Vilka möten har jag i morgon?”
  2. AI:n förstår att den behöver titta i kalendern. Den ser att kalender-servern har ett verktyg som heter hämta_möten och ber om att få använda det.
  3. Servern går in i kalendern och letar upp morgondagens möten.
  4. Kalendern svarar med tre möten.
  5. Servern skickar tillbaka listan till AI-appen i MCP:s gemensamma format.
  6. AI:n svarar dig med vanliga ord: ”Du har tre möten i morgon: kl 9, 13 och 15.”
Vanlig fråga

Vad är skillnaden mellan API och MCP?

Ett API är ett sätt för program att prata med ett system. Varje system har sitt eget API med egna regler, och en programmerare skriver kod som använder det.

MCP är en gemensam standard för hur AI-assistenter kopplar upp sig mot verktyg och data. Bakom en MCP-server finns oftast ett vanligt API. De konkurrerar alltså inte: MCP är ett lager ovanpå API:et, gjort så att en AI kan förstå och använda det.

Välj API

När allt ska ske likadant

Till exempel en nattlig överföring av data mellan två system. Samma steg varje gång, och ingen AI behövs.

Välj MCP

När en AI ska hjälpa till

Till exempel frågan ”Behöver jag paraply i Helsingborg i morgon?”. AI:n ser verktyget hämta_väderprognos, använder det och svarar med vanliga ord.

Tekniskt sett är MCP också ett slags API, fast ett standardiserat som är gjort för AI. Därför kallas det ibland ”ett API för AI-agenter”.

Säkerhet

Du har kontrollen

  • AI:n kommer bara åt de system som någon aktivt har kopplat in. Ingen server, ingen åtkomst.
  • Appen brukar fråga dig innan AI:n gör något, till exempel skickar ett mejl.
  • En server får bara de behörigheter du ger den. Ge inte mer än vad som behövs.
  • Använd bara servrar från källor du litar på, precis som med appar i mobilen.

Kom ihåg

  1. MCP är en standardkontakt som låter AI prata med andra program.
  2. Värd, klient och server: appen, kopplingen i appen och programmet som når systemet.
  3. AI:n kan då läsa information och göra saker åt dig, men bara där du har gett tillåtelse.
  4. MCP ersätter inte API:er. En MCP-server bygger oftast på ett vanligt API och gör det begripligt för en AI.

MCP släpptes av Anthropic i november 2024 som en öppen standard. Den används i dag av många AI-verktyg från olika företag, och vem som helst kan bygga en egen MCP-server.
